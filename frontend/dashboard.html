Instrucciones para preparar tu Excel / CSV

Si ya tienes un inventario en Excel, asegúrate de que la primera fila (encabezados) tenga exactamente estos nombres de columna y guárdalo como CSV UTF-8 (delimitado por comas) (*.csv):

nombre_equipo area subarea marca modelo sn nni garantia fecha_expgarantia estatusfuncional observaciones
  • sn / nni: Son opcionales; si un equipo no cuenta con ninguno, deja las celdas vacías (los equipos con SN o NNI duplicado se omiten automáticamente y no se permite subir el mismo archivo CSV dos veces).
  • garantia: Escribe SI o TRUE si tiene garantía vigente, o NO / FALSE si no tiene.
  • fecha_expgarantia: Formato AAAA-MM-DD (ej. 2027-06-30) solo cuando garantia sea SI.
  • estatusfuncional: Escribe SI / FUNCIONAL si opera correctamente, o NO si está fuera de servicio.
